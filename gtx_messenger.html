GTX MESSENGER — VERSION 1.6RELEASE
19 November 2026 • Developed by Garry

Your privacy matters to us.

We have removed the Administrator Conversation Inspector from GTX Messenger because we respect user privacy. The app no longer provides administrators with a built-in feature to open and read private conversations between users.

What's New in Version 1.7
Privacy-first administrator experience
The in-app Conversation Inspector and its conversation-reading controls have been removed. This describes the app interface; it does not replace Firebase security rules or the published privacy policy.
eDEX-inspired terminal theme
A futuristic interface skin with a technical grid, cyan highlights, subtle scanlines and terminal-style typography.
Four new color themes
eDEX UI, Oceanic, Solar Flare and Rose Quartz join the existing GTX themes.
Visual polish
Refined panel borders, accent glow, contrast and theme-specific surfaces while retaining the existing app layout.
Existing features retained
Existing messaging, accounts, groups, chats and Firebase project are retained by this UI update.

Version 1.7
Messenger Experience Update

  • Removed the eDEX UI theme from the theme picker and migrated saved eDEX selections to the standard Liquid Dark theme.

Administrator best-practice tips
  • Use a unique, strong password and enable Google account protection.
  • Grant admin privileges only to trusted accounts; never rely on hidden UI buttons as security.
  • Keep Firebase Realtime Database rules restrictive and test them with non-admin accounts.
  • Review reports consistently and document moderation actions without browsing private chats.
  • Never share Firebase service-account credentials or private keys in client-side HTML.
